# SM1 CinemaTools · download

Programma per sceneggiatura e produzione cinematografica di **Sanmartinouno Srl** (Bologna).

Qui ci sono solo gli installatori del programma per computer e l'elenco delle novità di ogni versione. Il programma installato controlla questa pagina a ogni apertura e propone l'aggiornamento.

Scarica l'ultima versione dalla sezione **Releases**:

- **Mac** (Apple Silicon): file `.dmg`. Aprilo e trascina SM1 CinemaTools nella cartella Applicazioni. La prima volta: clic destro sull'app → Apri.
- **Windows**: file `…_x64-setup.exe`. Se compare «Windows ha protetto il PC»: Ulteriori informazioni → Esegui comunque.

I progetti restano sul tuo computer (o nel tuo account cloud) e non vengono toccati dall'aggiornamento.
